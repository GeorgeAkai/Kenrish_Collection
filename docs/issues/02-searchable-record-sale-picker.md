# 02 Searchable Record Sale picker

Type: AFK

## What to build

On the Record Sale form in both shops, the admin picks an item from a single searchable dropdown, grouped by Beauty Products, Clothes and Handbags. Each option shows name, stock and price. Opening the dropdown lists everything. Typing filters with a case-insensitive "contains" match.

## Acceptance criteria

- [ ] The dropdown lists all items when opened, grouped by category
- [ ] Typing filters case-insensitively (`jAcK` finds "Jacket")
- [ ] Each option shows name, stock and price, and out-of-stock items are clearly marked
- [ ] Selecting an item fills the unit price as it does today
- [ ] Works in both the Beauty and Fashion shop views, scoped to each shop's items
- [ ] Usable by keyboard

## Blocked by

None - can start immediately
